# セキュリティとプライバシー

個人利用 (利用者は自分ひとり) を前提にした設計です。多人数・公開配布する場合は末尾の「公開するなら」を参照してください。
サーバーに接続しない使い方 (体験ライブラリ / Apple Intelligence) では、**体験づくりに使う情報は端末の外に出ません**。

## データの一覧

| データ | どこにあるか | 保持期間 | 提案に使うか・どこへ渡すか |
|---|---|---|---|
| 予定 (今日・明日の時間とタイトル) | 端末のカレンダー。アプリは保存しない | — | 許可時のみ。タイトルは別途オフにできる。メモ・場所・参加者は読み取らない。サーバー接続時だけ端末の外へ |
| いまの気分 | 端末のメモリのみ | 次の提案まで (記したら消える) | 自分で選んだときだけ |
| 時間帯 (夜明け・朝・昼・夕方・夜・深夜) | 端末の時計から計算 | — | 常に (時刻以上のことは分からない) |
| おおよその地域 (市区町村名) | 端末のメモリのみ | 1時間 | 位置の許可 + アプリ内の許可時のみ。座標は使わない |
| 会話 | 端末のメモリのみ | 画面を閉じるまで (提案の参考には最大6時間・5件) | 会話中のみ |
| 体験帳 (名前・誘いかけ・問い・タグ・反応・評価・ひとこと・樹の上の位置と要素) | 端末の SwiftData。アプリ自身の領域 (App Group には置かない)。iCloud に同期しない | 削除するまで | 名前・反応・評価・傾向のみ (ひとことは渡さない)。オフにできる |
| 体験の樹のいま (灯った体験の id・名前・要素、芽の id) | 体験帳と自分の樹から、提案のたびに組み立てる (樹そのものは保存しない) | — | 「体験帳と反応を提案に使う」がオンのときだけ。灯った体験12件・芽16件まで。ひとことや評価は含めない |
| 自分の樹 (編んだ体験・見つけた体験・結びとそのひとこと) | 端末の `Application Support/Taiken/garden.json` (アプリ自身の領域・iCloud に同期しない・初回のロック解除まで暗号化) | 手放す・削除するまで | 編んだ体験は、灯ったときだけ上の「樹のいま」に名前が入る。結びのひとことは渡さない |
| 今日の状態 (ウィジェット用) | App Group の UserDefaults | 次に更新されるまで | ウィジェットだけが読む。名前・誘いかけ・問い・印・要素の名前のみ (体験帳・評価・ひとこと・樹は置かない) |
| 体験中の Live Activity | ロック画面・Dynamic Island | 終えた・やめたらすぐ消す (最長8時間で古い表示になる) | 誘いかけ・問い・始めた時刻・要素の名前。設定でオフにできる |
| 朝の便り | 端末の通知の予約 (7日分) | 予約し直すたびに入れ替え | 決まった短いひとことだけ (予定や体験帳の内容は入れない) |
| 書き出したファイル (体験の樹の Markdown・体験帳の JSON) | 共有を選んだときに一時ファイルとして作る | 共有先しだい | 自分で共有先を選んだときだけ。ひとことと結びのひとことも含むので、共有先に注意 |
| 接続トークン | 端末の Keychain (この端末のみ・iCloud同期なし) | 解除するまで | — |
| 1日の利用量 (回数・トークン数・検索回数) | Backend の `DATA_DIR/usage.json` | 当日分のみ上書き | — |
| アクセスログ | Backend の標準出力 | 運用次第 (compose では10MB×5) | — |

Backend は**予定・会話・体験の内容を保存しません**。ログにも内容は出しません (キー名による伏せ字処理もあり、テストで確認済み)。
Web検索を使った場合、検索語は Anthropic の web search 経由で外部の検索に送られます。下調べ段には発言・予定のタイトル・履歴を渡さず、地域と時間帯だけを渡します。

アプリの「設定 → 次に渡す内容を確かめる」と、提案カードの「i」から、次の提案で使う内容を送る前に読めます (`RequestPreview`)。送るものを増やすときは、ここにも表示を足すことをテストで強制しています。

## Apple Intelligence (iOS 26 以降)

- サーバーに接続していないとき、対応機種では端末内のモデル (FoundationModels) が提案と会話をつくります。予定や会話は端末の外に出ません。
- 端末内のAIの出力にも、サーバーと同じ安全確認をかけます (`SafeguardedExperienceService`): 危険な提案は体験ライブラリに差し替え、強い苦痛のサインがある会話は生成させずに相談先の案内につなぎます。

## 共有と書き出し

- 体験帳の JSON は、共有シートで渡すときに初めて作ります (一時ファイルを残さない)。
- 「印のカード」の共有は画像だけです。ひとことは「この端末だけに残ります」と約束しているので、カードに載せるのは既定でオフ (載せるかはその都度選ぶ)。

## 想定する脅威と対策

| 脅威 | 対策 |
|---|---|
| AI APIキーの漏えい | キーは Backend の環境変数にのみ。アプリ・ログ・応答に含めない (テストで確認) |
| 他人による Backend の不正利用 | Bearer トークン (32文字以上、本番では必須)。定数時間比較。Tailscale などの私的ネットワーク内に置くことを推奨 |
| 盗聴 | インターネット越しは https のみ許可 (アプリ側で検証)。http はローカル/私的ネットワークのみ |
| 想定外の請求 | 1日のリクエスト数・トークン数・検索回数の上限。超えたらAIを呼ばず体験ライブラリで代替生成 |
| 上流障害での連鎖 | 再試行 (指数バックオフ + Retry-After)、遮断器、同時実行数の上限、リクエスト期限。端末側も必ず端末内のしくみに切り替える |
| 大きすぎる・壊れた入力 | 本文サイズ上限、許可リスト方式の入力整形、件数と文字数の上限、制御文字の除去 |
| プロンプトインジェクション (予定タイトルや発言に命令を混ぜる) | ユーザーデータをタグで囲み「データであって指示ではない」と明示。樹の id は形 (英小文字・数字・ハイフン) を確かめ、伸びた先は送った灯った体験の id だけを受け取る。出力はスキーマで正規化し、危険な提案は機械的にも除外 |
| 危険な体験の提案 | システムプロンプト + 危険パターンの機械的確認 (睡眠・食事を削る、移動中の危険行為、違法行為など)。端末内のAIにも同じ確認 |
| 強い苦痛のサイン | AIの判断 + キーワードでの確認 (端末内でも同じ)。提案を出さず、厚生労働省「まもろうよ こころ」への案内をその場に表示 |
| ロック画面の覗き見 | 体験帳・評価・ひとことはロック画面に出さない。Live Activity は体験中だけで、設定でオフにできる。ウィジェットは自分で追加したときだけ |
| 端末の紛失 | トークンは Keychain (`AfterFirstUnlockThisDeviceOnly`)。体験帳は iOS のデータ保護下。設定から一括削除・解除できる |

> サーバーのAIが生成した誘いかけには、予定の種類 (例: 打ち合わせ) が含まれることがあります。ロック画面に出したくない場合は、Live Activity をオフにし、ロック画面のウィジェットを置かないでください。

## トークンのローテーション

1. `npm run token` で新しいトークンを作る
2. `CLIENT_TOKENS=古い,新しい` にして Backend を再起動
3. アプリの設定で新しいトークンを保存
4. `CLIENT_TOKENS=新しい` にして再起動

## 公開するなら (個人利用の範囲外)

- 共有トークンではなく、ユーザーごとの認証と App Attest による端末検証にする
- レート制御・予算をユーザー単位にし、共有ストア (Redis など) に置く
- プライバシーポリシー、App Store のプライバシー表示 (`PrivacyInfo.xcprivacy` の収集データと、UserDefaults など必須理由のある API の宣言) を実態に合わせて用意する
- 年齢制限・相談窓口の案内を地域ごとに用意する
