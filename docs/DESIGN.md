# デザイン — 光と印

「体験」は、AIが一日を管理するアプリではありません。いつもの一日に、視点をひとつ差し出すアプリです。
使う人が思わず開きたくなるのは、通知や数字に追われるからではなく、開くたびに空が少し違い、生きた体験が樹として少しずつ伸びていくからです。

## 原則

1. **ひとつだけ差し出す。** 画面の真ん中には、その時いちばん大事なカードが一枚だけある (提案・体験中・記したところ・ひと休み)。提案は一度にひとつ。
2. **見方を渡す。やることは渡さない。** 誘いかけは「〜してみませんか？」で終え、目を向ける対象をひとつだけ具体的に含める (ひと口目の味、手が止まった瞬間、窓の外のいちばん遠いもの)。時刻・分数・手順は指定しない。
3. **断ることを、選択肢として同じ重さで置く。** 「やってみる」「別の視点」「今はやらない」。断ったら3時間は提案を控え、「断っても、何も減りません」とだけ言う。
4. **儀式にする。** 受け取る → やってみる → 思い返す → 印を押す → 樹に灯る。段階ごとに動きと触覚を変え、終えたことを体で確かめられるようにする。
5. **数で追い立てない。** 連続記録・バッジ・ランキング・未読バッジ・「今日もやろう」は置かない。体験の樹にも点数・レベル・解放の条件・達成率は無い。灯りは「どこに触れたか」を見せるもので、目標ではない。
6. **体験だけでできた場所にする。** 樹に置かれるのは、文章でもタスクでもなく、体験そのもの。つながりをたどって次の体験へ渡れるが、たどらなくてもよい。
7. **正直に。** どのしくみが提案をつくったかをカードに出す。事実 (予定・あなたの言葉) と推測を見た目で分ける。送る前に、次に渡す内容を確かめられる。
8. **サーバーが無くても、最後まで。** 体験ライブラリと Apple Intelligence で、体験の流れは端末の中で完結する。繋がらないときも黙って止まらない。

## 体験の樹

スキルツリーの形を借りているが、ゲームの仕組みは借りない。

| 借りるもの | 借りないもの |
|---|---|
| 根から枝が伸びる形。どこから来て、どこへ行けるかが見える | 経験値・レベル・ポイント・解放の条件 (どの体験も、いつでも始められる) |
| 灯った体験の先に、次の芽が見える | 「あと3つで完成」のような達成率。樹は完成しない |
| 要素 (見る・聴く・味わう…) ごとのまとまり | 要素ごとの数の比較・偏りの指摘 |

| 部品 | 決まりごと |
|---|---|
| 根 | 10の要素それぞれの「いちばん小さなかたち」の体験。内側の輪に、要素の字の入った丸として置く |
| 枝 | 体験ライブラリのつながり。深める (同じ要素で細やかに)・広げる (同じ要素で別の場面へ)・渡る (別の要素へ)。外へ向かう輪ほど、根から遠い |
| 灯り | 記した体験は朱の印になる。何度も記すと、印が少し重なる。数は目標として出さない (ページには「2回記した」とだけ書く) |
| 芽 | 灯った体験の先の、まだやっていない体験。呼吸する藍墨の丸。提案は芽を少しだけ前に出す (予定や気分に合う体験のほうが先) |
| 編んだ体験 | 自分で書いて植えた体験。小さな菱形。どこから伸ばすかを選べる。灯った体験から伸ばすと、その先の芽になる |
| 見つけた体験 | AIが新しく作り、自分でやってみることにした体験。ライブラリに無いので、やってみたときに樹に植わる |
| 結び | 灯った体験どうしを、自分で結んだ朱の糸。何が響き合ったかを40文字まで添えられる。外へ少しふくらんだ弧で描き、枝と見分ける |

画面は三つの見方を行き来する。

- **樹**: 空の上の放射状の図。指で動かし、つまんで拡大、二度押すと寄る。要素の札を押すと、その要素だけが濃くなり、そこへ寄る。体験を押すと、下に小さなカード (やってみる / ひらく)
- **一覧**: 要素ごとに根から順に、つながりの深さで字下げ。探す言葉で絞れる。VoiceOver のときは、はじめからこちら
- **体験のページ**: 誘いかけ・根からの道すじ・ここからひらく・ここへ至る・結んだ体験・記録。となりの体験へ、ページからページへ渡っていける

ホームの見出しの横には小さな樹 (灯りと芽だけ)。提案と体験中のカードには「枝」を一行添える (「ひと口目の観察」から伸びる枝 / 「見る」の根 — いちばん小さなかたち / 新しく見つけた体験 — やってみると樹に植わります)。押すと、樹の上のその場所がひらく。

## 見た目の言語「光と印」

| 要素 | 決まりごと |
|---|---|
| 地 | いまの時刻の空。夜明け・朝・昼・夕方・夜・深夜の6つ × ライト/ダーク。中ほどの光の溜まりがゆっくり漂い、夜は星が瞬く (`SkyBackground`)。時間帯が変わると1.4秒かけて移る |
| 面 | 障子越しの光のような半透明の紙 (`PaperCard`)。夜の空にライト表示で置くときは、灯りの下の紙のように明るくする |
| 文字 | 藍墨 (ink / ink2 / ink3 の3段)。誘いかけ・体験の名前・要素の字は明朝 (ヒラギノ明朝)、操作の文字はシステムのゴシック |
| 朱 | 朱肉の色。**印・灯り・結びの糸と、印に値する操作 (やってみる・記す・植える・結ぶ) にだけ**使う。トグルや戻るボタンは藍墨 |
| 印 | 体験の主な要素の字 (見・聴・香・味・触・動・休・考・言・人)。朱文 (枠) と白文 (塗り)。同じ文字はいつも同じ朱肉のかすれ方になる (`SealView`) |
| 要素の字 | 藍墨の細い枠に一文字 (`ElementMark`)。朱は記した印だけに使うので、要素そのものは藍墨 |
| アイコン | 夜明けの空に、白文の印「体」。ダーク (夜空) と色付きの版もある (`ios/tools/make_app_icon.py`) |

色の値は `ios/Shared/Design/Palette.swift` が正で、Web 版 (`docs/prototype/taiken.html`) も同じ値を使う。

## 動きと触覚

| 瞬間 | 動き | 触覚 |
|---|---|---|
| 提案が届く | 墨がにじむように、誘いかけ → 名前 → 視点 → 枝 の順に現れる (ぼかし → くっきり) | — |
| 別の視点 | カードが横に送られ、次のカードが入ってくる | — |
| 気分を選ぶ | 札が藍墨に変わる | 選択 (軽い) |
| やってみる | カードが落ち着き、朱の縁がゆっくり呼吸する | 中くらい |
| 記す | 振り返りのシートが閉じきってから、印が重さをもって押される (2.1倍 → 等倍、-16° → -6°)。少し遅れて「その先に、芽が出ました」 | 重い |
| 樹の芽 | 藍墨の丸がゆっくり呼吸する。体験中の印のまわりには朱の輪 | — |
| 樹を動かす | 指に吸いつくように。要素を選ぶ・二度押す・ページから「樹の上で見る」はばねで寄る | 体験を選ぶと選択 (軽い) |
| 返事が届く | 下から静かに現れる | 軽い |

「視差効果を減らす」がオンのときは、空と芽の呼吸は止まり、にじみ・送り・押印・寄る動きはすべて短い不透明度の変化かその場の切り替えに置き換える。触覚だけに意味を持たせない。

## 言葉づかい

- 誘いかけは「〜してみませんか？」。命令形・感嘆符・絵文字は使わない
- 評価は「響いた / ふつう / 合わなかった」。点数や星は使わない
- 樹の言葉は、育てる・解放する・達成する ではなく、灯る・芽が出る・伸ばす・編む・結ぶ・手放す
- 心理状態を決めつけない (「疲れているようですね」ではなく、選ばれた気分をそのまま受け取る)
- 疲れが見えるときは、負担を増やさない軽い提案にする。休みたい・聞いてほしいだけに見えるときは提案しない
- 強いつらさのサインがあれば、提案をやめ、その場に相談先を出す

## アクセシビリティ

- 文字はすべて Dynamic Type に合わせて大きくなる (明朝も `relativeTo:` で追従)。印と樹の上の字は形として扱い、大きさを固定する
- VoiceOver: 印は読み上げない (文字は隣の名前で伝わる)。樹の図は「体験の樹の図」とまとめて読み、「一覧で見る」の操作で一覧へ。VoiceOver がオンのときは、はじめから一覧を出す
- 一覧の行は「印・名前・誘いかけ・様子 (灯った / 芽)」をまとめて読む。要素の札は「灯りがあります」を値として伝える
- 結びの糸は、長押しのメニューと同じ「糸をほどく」を、読み上げの操作としても置く
- 暦のマスは「10月8日、ひと口目の観察」のようにまとめて読む。印のある日だけボタンになる
- 夜の空でも文字のコントラストを保つため、空の上の文字は空の明暗で切り替え、面は灯りの紙にする

## アプリの外

| 場所 | 出すもの | 出さないもの |
|---|---|---|
| ウィジェット (小・中・ロック画面) | 今日の誘いかけと、その要素。体験中はその体験。古い提案は出さず、日付とひとことにする | 体験帳・評価・ひとこと・樹 |
| Live Activity (体験中だけ) | 誘いかけ・問い・始めた時刻・要素 | 経過時間 (急かさない) |
| 朝の便り (既定オフ) | 一日一度。その日の小さな体験のきっかけ | 音。その日すでに体験に触れていれば送らない |
| 状況に合わせた通知 (既定オフ) | 提案する価値があり、今がよいタイミングのときだけ | 音・静かな時間帯・体験中・上限を超える回数 |
| ショートカット | 今日の体験 / 体験帳 / 体験の樹 / 話しかける を開く | 勝手に始める・記録する |
| 書き出し | 体験の樹 (Markdown の保管庫)・体験帳 (JSON) | 自動の同期・クラウドへの送信 |

## やらないこと

連続記録、バッジ、ランキング、経験値、レベル、解放の条件、達成率、他人との比較、無限に流れるフィード、赤い未読バッジ、音の鳴る通知、「◯日ぶりです」、AIによる性格の決めつけ。
