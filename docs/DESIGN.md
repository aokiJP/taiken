# デザイン — 生きた体験が、技になる

「体験」は、AIが一日を管理するアプリではありません。いつもの一日を自分で生きて、自分の言葉でひとこと記すと、その体験が触れた要素に経験として積もり、見方や力 (技) が少しずつ身についていく。そういう「技の樹」を育てるアプリです。
AIや体験ライブラリは、求めたときに「きっかけ」をひとつ差し出すだけです。

この文書は 4.0 の考え方と決まりごとをまとめたものです。技の中身の正は `contracts/skills.ja.json`、数え方の正は `ios/TaikenCore/Sources/TaikenCore/Tree/` にあります。

## 義務と体験

体験ライブラリの「〜してみませんか？」や、AIが作る提案は、具体的であるほど「やったか、やらなかったか」で測れるものになる。受け取ってこなした時点で、それはだれかに出された課題、つまり義務になる。3.0 までのホームは、真ん中に提案を一枚置いていた。言葉をどれだけやわらかくしても、毎日差し出される提案は「今日の分」になっていく。

体験は、自分で生きたものだ。何に目が留まったか、何が響いたかは、外から決められない。あとから自分の言葉で記したときに、はじめて形になる。

| | 義務 | 体験 |
|---|---|---|
| 決めるのは | 外 (AI・アプリ・だれか) | 自分 |
| 中身 | 先に、具体的に決まっている | あとから、自分の言葉で決まる |
| 終わり方 | こなすと消え、こなさないと残る | 記すと残る。やらなかったものは、どこにも残らない |
| 測り方 | できた / できなかった | 何に触れたか、何が身についたか |

だから 4.0 は、体験を渡すことをやめた。

- ホームの真ん中は、自分の樹と「体験を記す」。きっかけ (AI・体験ライブラリの提案) は「きっかけをもらう」を押したときだけ出る
- 樹の節は「やること」ではなく「できるようになること」(技)。「窓の外のいちばん遠いものを眺める」ではなく「遠目 — 景色の中のいちばん遠いものに、目が届く。」。こなして消すものではないので、チェックリストにならない
- 体験ライブラリの94の体験は、課題ではなく技の「稽古」になった。技の見方で、いつもの一日を過ごす入口。やってもやらなくても、技は減らない

## RPG の体験は何か

スキルツリーの形を本気で使うなら、RPG を遊んだあとに何が「体験」として残っているのかを考えなければならない。クエストの一覧や日課のミッションは、ゲームの中の義務にすぎない。残っているのは、次のようなものだ。

| RPG で体験になっているもの | なぜ体験になるのか | 技の樹での形 |
|---|---|---|
| 成長が見える | 見えない上達が、数や新しい力として目に見える | 記すと、触れた要素に「経験 +1」。升目が埋まり、段が上がる |
| 限られたものの使い道を選ぶ | 点が少ないから、選ぶことがその人らしさになる | 段がひとつ上がると、芽がひとつ。どの技へ伸ばすかは自分で選ぶ |
| 霧の向こうの気配 | 全部は見えないから、次が気になる | 名前が見えるのは、身についた技の隣だけ。その先は霧 |
| 隠されたものの発見 | 決められた手順ではなく、自分の遊び方から見つかる | 閃き。暮らし方から、ふっと現れる。条件は画面に出さない |
| 使い込んで、自分のものになる | 何度も使った剣や呪文は、数値以上に自分のもの | 身についた技は、使った記録が重なるほど 守 → 破 → 離 |
| 振り返ると、旅の記録になっている | 育てた跡が、そのまま自分の物語になる | 技のページの「この技とともにあった体験」、体験帳、Markdown の保管庫 |

反対に、RPG の中で義務になっている仕組みは入れない。

| RPG の仕組み | なぜ義務になるのか | 技の樹では |
|---|---|---|
| クエスト・日課・デイリーミッション | だれかが決めた「やること」が、終わるまで残る | 入れない。稽古ときっかけは、やらなくても何も減らない |
| ログインボーナス・連続記録 | 来なかった日を罰にする | 入れない。日を数える閃きも「続けて」ではなく「別々の日」 |
| 期限つきのイベント | 逃すことへの恐れで動かす | 入れない。芽は消えず、閃きにも期限はない |
| 経験の減少・衰え | 休むことを罰にする | 入れない。経験は時間では減らない |
| ランキング・他人との比較 | 他人の遊び方が物差しになる | 入れない。樹は自分のものだけ |
| 達成率・コンプリート | 「あと◯個」が新しい義務になる | 出さない。まだ閃いていない数も出さない。編んだ技で、樹はずっと伸びる |
| おすすめの育て方・自動の割り振り | 選ぶことを奪う | 出さない。芽は自分で使う |

3.0 は、経験値・レベル・解放の条件そのものを外していた。けれど人を追い立てていたのは数そのものではなく、数を義務に変える仕組み (期限・連続・減少・比較・達成率) だった。4.0 はその仕組みだけを外し、成長が見える・選ぶ・霧・発見・使い込む、という RPG の体験の本体を取り入れた。

## 参照元

RPG だけを手本にはしない。体験が身についていく様子は、ほかの世界からも借りた。

| 参照 | 借りたもの | 技の樹での形 |
|---|---|---|
| RPG のスキルツリー | 成長が見える・限られたものを選んで使う・隠れたものを見つける | 経験・段・芽・伸ばす・閃き |
| 稽古の世界 (守破離) | 型を守り (守)、自分のやり方が出て型を破り (破)、型を離れて自分のものになる (離)。稽古は「古 (いにしえ) を稽 (かんが) える」こと | 身についた技の深まり。体験ライブラリの体験は、技の「稽古」 |
| フィールドノート | 歩いた人が、その場で、自分の言葉で書き留める。書き留めたものが、あとで知になる | 中心の操作は「体験を記す」。自分の言葉でひとこと。書き出すと、要素・技・記録のページがつながった保管庫になる |
| Outer Wilds の霧と船の記録 | 先へ進ませるのは鍵ではなく、知ったこと。まだ確かめていない場所は「？」として記録に残り、どこにあるかだけが分かる | 霧の中の技は「？」と、どこにあるかだけ。隣の技が身につくと、名前と条件が見えてくる |
| 樹と年輪 | 樹は急がず、年ごとに輪を重ねる。輪は減らず、ほかの樹と比べられない | 十の要素の段の合計を「年輪」と呼ぶ |

## 原則

1. **体験は渡さない。記してもらう。** ホームの真ん中は、自分の樹と「体験を記す」。体験は、いつもの一日の中で自分で生きて、自分の言葉でひとこと記すもの。きっかけを見ているあいだも、自分で見つけた体験はいつでも記せる。
2. **節は「やること」ではなく、「できるようになること」。** 技の名前は、身につく見方や力の名前にする (稽古の体験と同じ名前にしない)。できるようになることは「〜できる」「〜が分かる」で書く。
3. **きっかけは、求められたときだけ。** AIや体験ライブラリの提案は「きっかけをもらう」を押したときだけ出す。朝の便りと「ちょうどよい時に知らせる」は、自分でオンにしたときだけ届く (はじめはオフ。オンにすることが「求める」こと)。きっかけも稽古も、やらなくても何も減らない。
4. **育ちは見せる。追い立てない。** 経験・段・芽は見える。経験は時間で減らず、芽は消えず、期限も連続記録も他人との比較もない。数は「いまどこにいるか」を知るためのもので、目標ではない。
5. **選ぶのは、その人。** 芽は段ひとつにひとつだけ。どの技へ伸ばすかは自分で選ぶ。自動では伸ばさず、おすすめの育て方も出さない。
6. **霧の向こうは、気配だけ。** 名前が見えるのは、身についた技の隣だけ。閃きの条件は画面にも書き出しにも書かない。
7. **使い込むほど、自分のものに。** 身についた技は、その技で過ごした記録が重なるほど、守 → 破 → 離 と深まる。
8. **自分の言葉は、自分のもの。** 自分で記した体験の言葉とひとことは、AIに送らない。体験帳と樹は端末の中だけにあり、いつでも書き出せる。
9. **正直に。** どのしくみがきっかけをつくったかをカードに出し、事実と推測を見た目で分ける。送る前に、次に渡す内容を確かめられる。
10. **サーバーが無くても、最後まで。** 体験ライブラリと Apple Intelligence で、体験の流れは端末の中で完結する。繋がらないときも黙って止まらない。

## 技の樹

### 経験と段

- 記した体験 (自分で見つけたものも、きっかけや稽古から始めたものも) が触れた要素に、それぞれ経験が 1 積もる。ひとつの記録で触れられる要素は3つまで。
- 段の境目は 1, 3, 6, 10, 15, 21 … (段 n に届くのに経験 n(n+1)/2)。はじめはすぐに上がり、だんだん間が広がる。
- 経験と段は、体験帳の記録から毎回数え直す (別に保存しない。食い違う二つの真実を持たない)。経験が減るのは、自分で記録を消したときだけ。そのときも、身についた技と閃きは残る。

### 芽と、伸ばすこと

- 段がひとつ上がるたびに、その要素に芽がひとつ出る。
- 芽をひとつ使って、条件のそろった技 (育てられる技) を伸ばすと、その技が身につく。渡り技は、ふたつの要素のどちらの芽でも伸ばせる。
- 芽は少ない。閃きと根を除く84の技に芽を使い切るには、段の合計が84、経験にして十の要素で400前後かかる。だから、どれを先に伸ばすかを選ぶことに意味がある。
- 芽は消えない。急がなくてよい。記録を消して段が下がり、同じ段に戻ったときは、その段の芽はもう使っているので新しくは出ない。

### 技の種類

| 技 | 数 | 届く条件 | 樹の上 |
|---|---|---|---|
| 根 (要素) | 10 | はじめからある。記すと段が刻まれる | 内側の輪。要素の字の丸 |
| 一の技 | 各要素に3 | その要素の一段 | 根のすぐ外 |
| 二の技 | 各要素に3 | 三段と、同じ要素の一の技 (ひとつずつ対応) | 一の技の外 |
| 奥義 | 各要素に1 | 六段と、二の技のうち二つ | 二の技の外 |
| 渡り技 | 14 | ふたつの要素のどちらも二段と、どちらかの一の技 | 要素のあいだ |
| 閃き | 9 | 書かない (暮らし方から) | 身につくまで樹に出ない。いちばん外の輪 |
| 編んだ技 | 自分で | 主な要素の一段 (伸ばす元を選べば、その技も) | 小さな菱形 |

### 技の様子

| 様子 | 見えるもの | 樹の上 |
|---|---|---|
| 霧 | どこにあるかだけ。名前も条件も見えない | 小さな点。ページでは「？」の印 |
| 気配 | 名前・できるようになること・届く条件 | 細い輪 |
| 育てられる | 条件がそろった。芽があれば「伸ばせる」 | 呼吸する芽 (いま伸ばせるときは朱) |
| 身についた | 深まり (守・破・離) と、この技とともにあった体験 | 朱の印。深まるほど、うしろに印が重なる。奥義は外に細い輪 |

一の技は、はじめから気配として見える (根の隣だから)。二の技・奥義・渡り技は、先の技がひとつ身につくと霧が晴れて気配になる。

### 閃き

- 9つ。条件は画面にも書き出しにも出さない。閃いたあとで「閃いたとき」(例: 夜明けの時間に、体験を記したとき) だけを見せる。
- 条件は、暮らし方の組み合わせだけで作る: 記した時間帯、ひとつの記録で触れた要素の重なり、記した日の数 (続けて、ではなく別々の日)、自分で見つけた体験の数、技どうしの結び、技の深まり。期限・連続・回数の多さを競う条件は使わない。きっかけや稽古をこなしたことは条件にしない。
- 早く出会うもの・しばらく暮らしていると出会うもの・長く使い込んで出会うもの・暮らし方によっては出会わないものが混ざるようにしている。
- 閃きは芽を使わない。一度閃いたら、体験帳を消しても消えない。
- 数を出さない (「残り3つ」とは書かない)。一覧に「樹のどこかに、まだ閃いていない技があります」とだけ書く。条件を知りたければ `contracts/skills.ja.json` にある (知らずにいたければ開かない)。

### 守・破・離

- 身についたときは守 (かたちを知った)。その技の稽古から始めた体験と、記すときに「使った技」に選んだ体験が合わせて3つで破 (自分のやり方が出てきた)、7つで離 (もう、あなたのもの)。
- 使った技は、記すときに自分で選ぶ。言葉から推し量った技には「かも」と添えるだけで、勝手には選ばない。稽古から始めた体験は、選ばなくてもその技に数える。

### 稽古ときっかけ

- 体験ライブラリの94の体験は、どれもいずれかの技の稽古。技のページの「やってみる」から始められる。やってもやらなくても、技は減らない。
- きっかけは、AIや体験ライブラリからのひとつの提案。「きっかけをもらう」を押したときだけ出る。選ぶときは、身についた技・育てられる技の稽古を少しだけ前に出す (予定や気分に合う体験のほうが先)。
- きっかけを「やってみる」と体験中になり、終えて記すと、ほかの記録と同じように経験が積もる。断っても何も減らない。

### 編む・結ぶ

- **編む**: 暮らしの中で身につきかけている自分だけの見方や力に、名前をつけて樹に植える (名前12文字・できるようになること40文字・自分の稽古120文字まで、要素は2つまで)。植えただけでは身についていない。伸ばすには、ほかの技と同じく芽を使う。手放すと、使った芽は戻る。
- **結ぶ**: 身についた技どうしを朱の糸で結び、何が響き合ったかを40文字まで添える。外へ少しふくらんだ弧で描き、枝と見分ける。

### 3.0 から来たとき

3.0 までの体験帳から経験と段を数え直し、はじめて開いたときに一度だけ「これまでの体験が、樹になっていました」と見せる。芽は使わずに残してあり、どの技へ伸ばすかは自分で選ぶ。3.0 で編んだ体験は「編んだ技」として残る。

## 画面

- **ホーム**: 見出しの横に小さな技の樹。真ん中は「技の樹」のカード (十の要素の段と次の段までの升目・芽・「体験を記す」・「きっかけをもらう」)。きっかけをもらうと、その場所にきっかけのカードが一枚だけ出る (やってみる / 別の視点 / 今はやらない)。その下に、自分で見つけた体験を記す入口を残す
- **体験を記す**: 自分の言葉でひとこと (60文字まで)、触れた要素 (言葉から推し量り、選び直せる。3つまで)、使った技 (なくてもよい)。記すとどの要素がどう伸びるかを、記す前に見せる
- **記したところ**: シートが閉じきってから印が押され、経験・段・芽・閃き・深まりをその場で見せる。芽が出たら「「見る」の芽を使って、技を伸ばす」
- **技の樹**: 樹 (空の上の放射状の図) と一覧を行き来する。技を押すと、下に小さなカード (伸ばす / ひらく)
- **技のページ**: できるようになること・届く条件・深まり・稽古・ここから伸びる / ここから来た・結んだ技・この技とともにあった体験。要素のページ (根) は、段と経験と芽・この要素の技・稽古・この要素に触れた体験
- **体験帳**: 要素の段・月の暦に押された印・日ごとの記録・最近の傾向。記録のページには「この記録で育った技」

## 見た目の言語「光と印」

| 要素 | 決まりごと |
|---|---|
| 地 | いまの時刻の空。夜明け・朝・昼・夕方・夜・深夜の6つ × ライト/ダーク。中ほどの光の溜まりがゆっくり漂い、夜は星が瞬く (`SkyBackground`)。時間帯が変わると1.4秒かけて移る |
| 面 | 障子越しの光のような半透明の紙 (`PaperCard`)。夜の空にライト表示で置くときは、灯りの下の紙のように明るくする |

| 朱 | 朱肉の色。**印・身についた技・伸ばせる芽・結びの糸と、印に値する操作 (記す・伸ばす・やってみる・植える・結ぶ) にだけ**使う。トグルや戻るボタンは藍墨 |

| アイコン | 夜明けの空に、白文の印「体」。ダーク (夜空) と色付きの版もある (`ios/tools/make_app_icon.py`) |

## 動きと触覚

| 瞬間 | 動き | 触覚 |
|---|---|---|
| きっかけが届く | 墨がにじむように、誘いかけ → 名前 → 視点 → 枝 の順に現れる (ぼかし → くっきり) | — |
| 別の視点 | カードが横に送られ、次のカードが入ってくる | — |
| 気分を選ぶ | 札が藍墨に変わる | 選択 (軽い) |
| やってみる | カードが落ち着き、朱の縁がゆっくり呼吸する | 中くらい |
| 記す | 記す・振り返りのシートが閉じきってから、印が重さをもって押される (2.1倍 → 等倍、-16° → -6°)。少し遅れて、経験・段・芽・閃き・深まりが現れる | 重い |
| 伸ばす | 確かめてから、技の印が押され、樹の上に「「◯」が身につきました」と知らせる | 重い |
| 閃く | 傾けた朱の印「閃」と、閃いたときの一文が現れる | (記す・伸ばす・結ぶの触覚と一緒) |
| 樹の芽 | 育てられる技の芽がゆっくり呼吸する。根の朱の点 (使える芽) も | — |
| 樹を動かす | 指に吸いつくように。要素を選ぶ・二度押す・ページから「樹の上で見る」は、ばねで寄る | 節を選ぶと選択 (軽い) |
| 返事が届く | 下から静かに現れる | 軽い |

「視差効果を減らす」がオンのときは、空と芽の呼吸は止まり、にじみ・送り・押印・寄る動きはすべて短い不透明度の変化かその場の切り替えに置き換える。触覚だけに意味を持たせない。

## 言葉づかい

### 技の樹の言葉

| 言葉 | 意味 | 使わない言葉 |
|---|---|---|
| 技の樹 | 十の要素の根から技が伸びる、自分の樹。体験を記すと育つ | スキルツリー (画面では) |
| 技 | 身につく見方や力。名前は見方や力の名前にし、「〜できる」「〜が分かる」で説明する | スキル・能力・アビリティ・お題 |
| 要素・根 | 見る・聴く・嗅ぐ・味わう・触れる・動く・休む・考える・言葉にする・人と。根は樹の内側の輪 | ステータス・属性 |
| 記す | いつもの一日で体験したことを、自分の言葉でひとこと書き留める。きっかけから始めた体験を終えるときも「記す」 | 完了・達成・クリア・チェック・投稿 |
| 経験 | 記した体験が触れた要素に積もるもの。ひとつの記録で、触れた要素それぞれに +1。時間では減らない | 経験値・XP・ポイント |
| 段 | 要素ごとの経験の深さ。境目は 1, 3, 6, 10, 15 … 漢数字で「三段」 | レベル・Lv・ランク |
| 年輪 | 十の要素の段の合計。樹が重ねてきたもの | 総合レベル・スコア |
| 芽 | 段がひとつ上がるたびに、その要素に出る。技をひとつ伸ばすのに使う。消えない | スキルポイント・SP |
| 伸ばす | 芽を使って、育てられる技を身につける | 解放・習得・アンロック・購入 |
| 身につく | 技が自分のものになる (身についた技) | 獲得・習得済み・解放済み |
| 育てられる | 届く条件 (段と先の技) がそろった。芽があれば「伸ばせる」 | 解放可能 |
| 気配 | 名前・できるようになること・届く条件が見える。まだ届かない | ロック中 |
| 霧 (霧の中) | まだ名前が見えない。どこにあるかだけ分かる | 未解放・??? |
| 閃き | 暮らし方から、ふっと身につく技。条件は書かない。芽を使わない | 実績・トロフィー・隠し実績 |
| 一の技・二の技 | 一段から届く技と、三段から一の技の先に届く技 (各要素に3つずつ) | 初級・中級 |
| 奥義 | 六段から、二の技のうち二つの先に届く、要素ごとにひとつの技 | 究極技・最終スキル |
| 渡り技 | ふたつの要素のあいだの技。どちらの芽でも伸ばせる | 複合スキル |
| 守・破・離 | 身についた技の深まり。使った記録が3つで破、7つで離 | 熟練度・ランクアップ |
| 稽古 | 技の見方で、いつもの一日を過ごす入口 (体験ライブラリの体験)。やらなくても減らない | 課題・ミッション・クエスト・タスク・ノルマ |
| きっかけ | AIや体験ライブラリからの、ひとつの提案。求めたときだけ | 今日のお題・おすすめ・デイリー |
| 編む | 自分だけの見方や力に名前をつけて、樹に植える | 作成・カスタムスキル |
| 結ぶ・ほどく | 身についた技どうしを朱の糸でつなぐ・はずす | リンク・連携 |
| 手放す | 編んだ技を樹から外す (使った芽は戻る) | 削除 (技について) |
| 印 | 記した体験に押される朱の印 | スタンプ・バッジ |
| 体験帳 | 記した体験の帳面。端末の中だけ | 履歴・ログ |

### 書き方の約束

- 技の名前は10文字まで、読みはひらがな。体験ライブラリの体験と同じ名前にしない (`check_skills.py` が確かめる)
- できるようになることは40文字までの一文で、「。」で終える。身についたあとの自分を「〜できる」「〜が分かる」「〜が聞こえる」のように書く。命令・お題・「〜してみませんか？」にしない。名前を繰り返さない。段・芽・結ぶ のようなアプリの言葉と紛れる言い方をしない (段の数は `check_skills.py` が弾く)
- 閃いたときは「〜とき」で書き、閃いたあとにだけ見せる
- 要素の名前は「休む」「人と」のように動詞や助詞で終わるので、文の中で助詞を続けるときは鉤括弧でくくる (「人と」に、芽が出ています)。三つ以上なら「五つの要素」とまとめる
- 季節の言葉 (季節・春夏秋冬・旬・節気・七十二候 など) は使わない (`check_content.py`・`check_skills.py` が弾く)。いつでも・どこでも同じように使える、ふつうの日付と時間帯で書く
- 誘いかけ (稽古・きっかけ) は「〜してみませんか？」で終え、目を向ける対象をひとつだけ具体的に含める。時刻・分数・手順は指定しない。命令形・感嘆符・絵文字は使わない
- 評価は「響いた / ふつう / 合わなかった」。点数や星は使わない
- 急かさない。「急がなくても、芽は消えません」とは書くが、「あと◯で完成」「もっと伸ばそう」「レベルアップ」「◯日ぶり」「今日もやろう」は書かない
- 心理状態を決めつけない (「疲れているようですね」ではなく、選ばれた気分をそのまま受け取る)
- 疲れが見えるときは、負担を増やさない軽いきっかけにする。休みたい・聞いてほしいだけに見えるときは提案しない
- 強いつらさのサインがあれば、提案をやめ、その場に相談先を出す

## アクセシビリティ

- 文字はすべて Dynamic Type に合わせて大きくなる (明朝も `relativeTo:` で追従)。印と樹の上の字は形として扱い、大きさを固定する
- VoiceOver: 印は読み上げない (文字は隣の名前で伝わる)。樹の図は「技の樹の図」とまとめて読み、樹の要約 (芽が出ている要素など) を値として伝える。「一覧で見る」の操作で一覧へ。VoiceOver がオンのときは、はじめから一覧を出す
- 一覧の行は「名前・できるようになること・様子 (身についた / 伸ばせる / 育てられる / 気配)」をまとめて読む。霧の中の技は「まだ霧の中の技」と読む
- 要素の段は「見る、三段」と読み、「経験 8、次の段まで あと2、芽が出ています」を値として伝える
- 届く条件の行は「そろっています / まだです」を値として伝える
- 結びの糸は、長押しのメニューと同じ「糸をほどく」を、読み上げの操作としても置く
- 暦のマスは「10月8日、机の上の地図」のようにまとめて読む。印のある日だけボタンになる
- 夜の空でも文字のコントラストを保つため、空の上の文字は空の明暗で切り替え、面は灯りの紙にする

## アプリの外

| 場所 | 出すもの | 出さないもの |
|---|---|---|
| ウィジェット (小・中・ロック画面) | 体験中はその体験。きっかけをもらっていれば、そのきっかけと要素。ふだんは日付とひとこと、押すと「体験を記す」 | 体験帳・評価・ひとこと・樹・段 |
| Live Activity (体験中だけ) | 誘いかけ・問い・始めた時刻・要素 | 経過時間 (急かさない) |
| 朝の便り (既定オフ) | 一日一度、きっかけをひとつ。オンにすることが「求める」こと | 音。その日すでに体験に触れていれば送らない |
| ちょうどよい時に知らせる (既定オフ) | 提案する価値があり、今がよいタイミングのときだけ | 音・静かな時間帯・体験中・上限を超える回数 |
| ショートカット | 体験を記す / ホーム / 体験帳 / 技の樹 / 話しかける を開く | 勝手に記す・始める |
| 書き出し | 技の樹 (Markdown の保管庫: 要素・見えている技・記した日のページが `[[リンク]]` でつながる)・体験帳 (JSON) | 霧の中の技・閃きの条件。自動の同期・クラウドへの送信 |

## やらないこと

連続記録、ログインボーナス、期限、経験の減少、バッジ、ランキング、他人との比較、達成率、コンプリート、おすすめの育て方、自動で技を伸ばすこと、無限に流れるフィード、赤い未読バッジ、音の鳴る通知、「◯日ぶりです」、求められていないきっかけ、AIによる性格の決めつけ。
