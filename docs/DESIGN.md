# デザイン — 光と印

「体験」は、AIが一日を管理するアプリではありません。いつもの一日に、視点をひとつ差し出すアプリです。
使う人が思わず開きたくなるのは、通知や数字に追われるからではなく、開くたびに空が少し違い、押した印が少しずつ増えていくからです。

## 原則

1. **ひとつだけ差し出す。** 画面の真ん中には、その時いちばん大事なカードが一枚だけある (提案・体験中・記したところ・ひと休み)。提案は一度にひとつ。
2. **見方を渡す。やることは渡さない。** 誘いかけは「〜してみませんか？」で終え、目を向ける対象をひとつだけ具体的に含める (ひと口目の味、手が止まった瞬間、窓の外のいちばん遠いもの)。時刻・分数・手順は指定しない。
3. **断ることを、選択肢として同じ重さで置く。** 「やってみる」「別の視点」「今はやらない」。断ったら3時間は提案を控え、「断っても、何も減りません」とだけ言う。
4. **儀式にする。** 受け取る → やってみる → 思い返す → 印を押す。段階ごとに動きと触覚を変え、終えたことを体で確かめられるようにする。
5. **数で追い立てない。** 連続記録・バッジ・ランキング・未読バッジ・「今日もやろう」は置かない。体験帳の数字は目標ではなく、出会った季節の記述 (この一年で出会った候 N / 72)。
6. **正直に。** どのしくみが提案をつくったかをカードに出す。事実 (予定・あなたの言葉) と推測を見た目で分ける。送る前に、次に渡す内容を確かめられる。
7. **サーバーが無くても、最後まで。** 体験ライブラリと Apple Intelligence で、体験の流れは端末の中で完結する。繋がらないときも黙って止まらない。

## 見た目の言語「光と印」

| 要素 | 決まりごと |
|---|---|
| 地 | いまの時刻の空。夜明け・朝・昼・夕方・夜・深夜の6つ × ライト/ダーク。中ほどの光の溜まりがゆっくり漂い、夜は星が瞬く (`SkyBackground`)。時間帯が変わると1.4秒かけて移る |
| 面 | 障子越しの光のような半透明の紙 (`PaperCard`)。夜の空にライト表示で置くときは、灯りの下の紙のように明るくする |
| 文字 | 藍墨 (ink / ink2 / ink3 の3段)。誘いかけ・体験の名前・季節の名前は明朝 (ヒラギノ明朝)、操作の文字はシステムのゴシック |
| 朱 | 朱肉の色。**印と、印に値する操作 (やってみる・記す・送る) にだけ**使う。トグルや戻るボタンは藍墨 |
| 印 | 体験の性質を一文字で表す (新・問・試・観・感・思・縁・創・刻…)。朱文 (枠) と白文 (塗り)。同じ文字はいつも同じ朱肉のかすれ方になる (`SealView`) |
| 短冊 | 七十二候の名前を縦書きで (`TanzakuView`)。押すと季節の輪のシートが開く |
| アイコン | 夜明けの空に、白文の印「体」。ダーク (夜空) と色付きの版もある (`ios/tools/make_app_icon.py`) |

色の値は `ios/Shared/Design/Palette.swift` が正で、プロトタイプ (`docs/prototype/taiken.html`) も同じ値を使う。

## 動きと触覚

| 瞬間 | 動き | 触覚 |
|---|---|---|
| 提案が届く | 墨がにじむように、誘いかけ → 名前 → 視点の順に現れる (ぼかし → くっきり) | — |
| 別の視点 | カードが横に送られ、次のカードが入ってくる | — |
| 気分を選ぶ | 札が藍墨に変わる | 選択 (軽い) |
| やってみる | カードが落ち着き、朱の縁がゆっくり呼吸する | 中くらい |
| 記す | 振り返りのシートが閉じきってから、印が重さをもって押される (2.1倍 → 等倍、-16° → -6°) | 重い |
| 返事が届く | 下から静かに現れる | 軽い |

「視差効果を減らす」がオンのときは、空は止まり、にじみ・送り・押印はすべて短い不透明度の変化に置き換える。触覚だけに意味を持たせない。

## 言葉づかい

- 誘いかけは「〜してみませんか？」。命令形・感嘆符・絵文字は使わない
- 評価は「響いた / ふつう / 合わなかった」。点数や星は使わない
- 心理状態を決めつけない (「疲れているようですね」ではなく、選ばれた気分をそのまま受け取る)
- 疲れが見えるときは、負担を増やさない軽い提案にする。休みたい・聞いてほしいだけに見えるときは提案しない
- 強いつらさのサインがあれば、提案をやめ、その場に相談先を出す

## アクセシビリティ

- 文字はすべて Dynamic Type に合わせて大きくなる (明朝も `relativeTo:` で追従)。印と短冊は形として扱い、大きさを固定する
- VoiceOver: 印は読み上げない (文字は隣の名前で伝わる)。短冊は「七十二候 鴻雁来（こうがんきたる）について」。振り返りの選択肢は選択状態を伝え、「記す」は選ぶまで押せない理由をヒントで伝える
- 暦のマスは「10月8日、渡っていくもの」のようにまとめて読む。印のある日だけボタンになる
- 夜の空でも文字のコントラストを保つため、空の上の文字は空の明暗で切り替え、面は灯りの紙にする

## アプリの外

| 場所 | 出すもの | 出さないもの |
|---|---|---|
| ウィジェット (小・中・ロック画面) | 今日の誘いかけと七十二候。体験中はその体験。古い提案は出さず、季節だけにする | 体験帳・評価・ひとこと |
| Live Activity (体験中だけ) | 誘いかけ・問い・始めた時刻・今日の候 | 経過時間 (急かさない) |
| 朝の便り (既定オフ) | 一日一度。その日の節気と候のひと言 | 音。その日すでに体験に触れていれば送らない |
| 状況に合わせた通知 (既定オフ) | 提案する価値があり、今がよいタイミングのときだけ | 音・静かな時間帯・体験中・上限を超える回数 |
| ショートカット | 今日の体験 / 体験帳 / 話しかける を開く | 勝手に始める・記録する |

## やらないこと

連続記録、バッジ、ランキング、他人との比較、無限に流れるフィード、赤い未読バッジ、音の鳴る通知、「◯日ぶりです」、AIによる性格の決めつけ。
